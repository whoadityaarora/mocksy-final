# **App Name**: Brand Identity Studio

## Core Features:

- Image Upload and Processing: Allows users to upload their logo image for brand identity generation.
- Brand Details Input: Enables users to input brand name, main color, desired style, and merchandise items for customization.
- AI-Powered Mockup Generation: Leverages Gemini Flash to generate high-quality studio mockup images that show the brand's visual designs on selected merchandise, following a 2x3 grid layout, applying spacing and visual hierarchy, after incorporating the user's uploaded logo. The LLM is a tool to achieve this feature.
- Real-time Status and Error Handling: Provides real-time updates on the generation process, including error messages and status indicators.
- Generated Image Display: Displays the AI-generated mockup image in high resolution within the app.
- Image Download: Enables users to download the generated brand identity mockup image.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082), evoking sophistication and creativity. 
- Background color: Light gray (#F0F0F0), offering a clean, neutral backdrop to focus on brand assets. 
- Accent color: Vibrant cyan (#00FFFF), for interactive elements and highlights, creating contrast.
- Font: 'Inter', a sans-serif font that will be used for the body and the headline due to its modern, neutral, machined look, which provides legibility and a contemporary feel.
- Simple, professional icons from Lucide-React library.
- Clean and structured layout with clear sections for input, status, and output to improve the user experience.
- Subtle loading animations to show system activity during the AI generation process.
